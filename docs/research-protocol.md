# Semantic moderation evaluation

The research target is a safety classifier, not an adversarial prompt generator. Civil Comments (https://huggingface.co/datasets/google/civil_comments) provides human annotation fractions; binarize toxicity at 0.5. Run unitary/toxic-bert locally via Transformers/PyTorch (Apache-2.0 model card: https://huggingface.co/unitary/toxic-bert). Use separate official validation and test splits, reproducible bounded-buffer shuffle, 500 examples per split by default. Choose F1-maximizing threshold on validation, report both fixed 0.5 and tuned operating points on test, ROC AUC, average precision and Brier score. This sampling is not a uniform full-corpus sample. Record revisions and content hashes; pin dataset/model revisions for reproducibility. Raw text is not exported or committed. Dataset may contain offensive material. Toxicity is not equivalent to overall LLM safety; annotations reflect disagreement and context, and model training overlap must be investigated. No live model score is claimed until actual execution. Subgroup metric utility is provided for separately labeled data; subgroup evaluation is not performed by the default experiment.
